### Descrição do projeto

O LevelUp é uma aplicação web voltada para apresentar informações
sobre diferentes jogos e seus personagens.

O site apresenta jogos como Far Cry 4, The Last of Us Part I,
The Last of Us Part II e Hollow Knight, reunindo informações sobre
suas histórias, personagens e universos.

Futuramente, o projeto poderá apresentar informações mais detalhadas
sobre personagens, habilidades, armas, facções, mapas, relações e
acontecimentos importantes de cada jogo.
